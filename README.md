# نظام مختبر التميز الطبي التخصصي

برنامج متكامل لإدارة المختبرات الطبية باللغة العربية.

## أهداف البرنامج
- تسجيل بيانات المرضى.
- طلب الفحوصات الطبية.
- إدخال نتائج التحاليل وحفظها.
- طباعة تقارير المختبر بتصميم احترافي.
- إدارة الفحوصات والأسعار.
- حفظ وأرشفة النتائج.
- البحث عن نتائج المرضى السابقة.
- النسخ الاحتياطي واستعادة البيانات.
- استقبال نتائج الأجهزة المخبرية تلقائياً عند توفر الاتصال.

## الأجهزة المستهدفة
- الهواتف Android.
- أجهزة الكمبيوتر.

## المختبر
مختبر التميز الطبي التخصصي

## اللغة
العربية والإنجليزية.
